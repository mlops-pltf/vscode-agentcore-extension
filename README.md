# AgentCore Chat

Direct chat extension for listing and invoking AWS Bedrock AgentCore agents from VS Code using your local AWS SSO profile.

## Prerequisites
- **Python 3.9+** installed on your machine
- Configured **AWS SSO Profile** in `~/.aws/config`

## Usage
1. Click the **AgentCore Chat** icon in the VS Code Activity Bar.
2. On first launch, wait a few seconds while the extension sets up its local Python environment.
3. Select your **AWS SSO Profile** and choose an agent from the dropdown to start chatting.
